# Data and Licenses

Benchmark data, associated images, and model weights are not redistributed here.

The public release will provide data-access instructions, attribution, and license
information for each external resource before reproduction materials are added.

## M4 metadata

`data/manifests/` contains only subset membership IDs and provenance/validation metadata. It contains no benchmark questions, answers, answer options, labels, images, predictions, or judge artifacts. Obtain and prepare BBQ and BBQ-V from their upstream sources before using the manifests or generator.
